# 崩坏：星穹铁道（`hkrpg-widget`）

复刻米游社官方「崩坏：星穹铁道」桌面小部件：开拓力（含回满倒计时）、每日实训 / 周期积分 / 活动剩余天数、
当期跃迁角色剩余天数、当期挑战。**4×2 与 4×4 共用一份脚本**（按 `ctx.sizeClass()` 分支）。

## 装完先填两个变量

应用「变量」页 → 本脚本：

| 变量 | 说明 |
|---|---|
| `cookie` | 米游社 Cookie，必须含 `cookie_token_v2`（浏览器登录米游社后从开发者工具复制整条 Cookie） |
| `roleId` | 游戏角色 ID（游戏内「个人资料」里的 UID 数字，如 `100034908`） |

`server` 留空按国服 `prod_gf_cn`；`launch` 留空点「启动游戏」打开 `com.miHoYo.hkrpg`。
`bg` 可填角色名/ID 固定 4×4 背景，留空则用内置全员画稿 + 桌面「换背景」按钮循环切换（99 张卡面）。

## 数据与隐私

- 数据来自米游社官方小组件接口（与游戏内「工具箱」同源），**只用你填的 Cookie 读取你自己的账号数据**，
  脚本不含任何账号信息、不向第三方发送数据；
- 接口不需要 `DS` 签名，Cookie 过期后组件会显示「Cookie 已失效」，在变量页更新即可；
- 取数节流：最短 10 分钟一次，两次取数之间按 6 分钟/点本地推算开拓力，离线也能算出回满时间。
