# ZEEHO 车辆（`zeeho-scooter`）

春风动力 ZEEHO / CFMOTO 电动车小组件（4×2）：电量、剩余续航、充电状态、胎压（前/后）、
今日骑行、总积分。**只做信息展示，不执行任何任务操作**（没有签到、抽奖、社区任务）。

## 装完先填变量

应用「变量」页 → 本脚本，只有一项：

| 变量 | 说明 |
|---|---|
| `token` | ZEEHO App 登录 Token（抓包 `tapi.zeehoev.com` 请求头里的 `Authorization: Bearer …`，填 Token 本身即可） |

> Token 是账号凭据，只存在你自己的设备上；脚本里不含任何账号信息，也不会把数据发往第三方。

## 说明

- 车辆自动识别：首次运行调「车辆列表」取第一辆车的 VIN 并缓存，多辆车时默认显示第一辆；
- 刷新节流：最短 5 分钟发一次真实请求，桌面曝光刷新的其余时间都用缓存快照渲染，
  所以组件不会因为频繁曝光而反复请求接口；
- Token 失效（HTTP 401/403）时组件显示「Token 失效」，在变量页更新即可；
- 数据来源与 ZEEHO App 同源（签名算法一致），仅供个人查看自己的车辆状态。
