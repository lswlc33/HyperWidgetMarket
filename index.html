澎湃组件 脚本市场

用户 JavaScript 自定义澎湃 OS 桌面小组件。所有脚本都是单文件 JS + 资源文件夹，安装后可在应用内编辑、在「变量」页配置。

怎么安装

  1. 推荐：应用内市场页——打开「澎湃组件」→ 底栏「市场」→ 找到脚本 → 安装。带资源的脚本会连 assets/ 一起装到 Download/HyperWidget/，并自动出现在脚本列表里。
  2. 手动安装——下载脚本的 <id>.js 放到 Download/HyperWidget/； 如果脚本带静态资源，再把它的 assets/ 文件夹放到 Download/HyperWidget/<id>/assets/ （没有资源则不用建文件夹）。应用需要「所有文件访问」授权才能读取公共目录。

脚本以 Rhino 引擎执行，能力与自建脚本相同（可申请 shell / 文件 / 网络）。请只安装你信任的来源，安装前在详情页确认它的能力标签。
